# 可维护性维度评分规则

## 单条问题评分（score: 0-100）

- 初始分：50
- 加分项：
  - +35：结构性缺陷明显（重复逻辑、耦合失控、职责混乱）
  - +25：显著增加后续修改成本或引发高回归风险
  - +15：扩展点被硬编码封死，演进困难
  - +10：问题定位和复现边界清楚
  - +25：可变/链式查询构造对象在多次查询间共享，链式状态相互污染，导致结果错误或回归风险
- 减分项：
  - -30：仅编码风格偏好，不影响可维护性
  - -20：证据不足，无法在 diff 中确认
  - -10：成本评估不明确
- 结果约束：最终分数限制在 0-100
